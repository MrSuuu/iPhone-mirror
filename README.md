# iPhone 镜像（iPhone Mirror for macOS）

一款自研的 macOS 端 iPhone 画面镜像客户端。纯 Swift 实现，自定义 RFB 协议解析与渲染，
把手机屏幕实时投射到 Mac 窗口里，并支持把触摸/点击/滑动直接映射回手机。

> 本项目为**闭源分发**，仓库仅提供安装包，不公开源代码。

## ✨ 功能

- **🖥️ 窗口化镜像**：窗口按手机比例自适应，画面完整显示、任意缩放无黑边
- **👆 触摸映射**：鼠标操作直接映射为手机触摸（点按 / 拖动 / 滑动）
- **🖱️ 鼠标手势**：
  - 左键拖动 = 触摸屏幕
  - 单击右键 = 回主屏（Home）
  - 双击右键 = 打开后台（App Switcher）
  - 滚轮上/下 = 手指向上/向下滑动屏幕
- **🔌 USB / Wi-Fi 双通道**：数据线优先，自动切换，掉线自动重连
- **🗜️ 手机机身外观**：圆角机身 + 金色边框 + 灵动岛，拖边框移动、拖右下角缩放
- **📐 窗口大小百分比**：设置里按百分比缩放，横竖屏保持同一比例
- **⚡ 画面优化**：zlib 压缩（省带宽约 30 倍）、可选画质与帧率上限

## 📦 安装

1. 下载 `iPhoneMirror.dmg`
2. 打开 DMG，把 **iPhone 镜像** 拖进 **Applications** 文件夹
3. 首次打开若提示「无法验证开发者」，请 **右键点击 App → 打开**（自签名应用的通用步骤）

> 要求：macOS 12 及以上。手机端需已具备可连接的 RFB/VNC 服务。

## ⚙️ 使用

打开 App 后进入 **左上角菜单（软件名）→ 连接设置**，填入手机端 RFB 服务的 IP / 端口 / 密码，
可保存多条连接并备注设备名。点「窗口大小」可按百分比缩放窗口。
